# Huevo interactivo

Aplicación web muy simple para pruebas: un huevo que, tras cinco clics, muestra un pollito.

## Cómo ejecutarla

1. Abre el archivo `index.html` directamente en tu navegador (doble clic) **o** levanta un servidor local con:

   ```bash
   python -m http.server 8000
   ```

2. En el navegador, entra a `http://localhost:8000` (o abre `index.html`).

3. Haz clic en el huevo cinco veces para ver al pollito aparecer. El texto inferior irá contando tus clics y te avisará cuando falte solo uno.

> Para compartirlo, puedes subir estos dos archivos a un repositorio de GitHub y habilitar GitHub Pages, pero no es obligatorio para probarlo en tu equipo.
